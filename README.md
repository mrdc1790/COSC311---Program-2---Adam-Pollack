# COSC 311 Program 2

An archived Java data structures assignment. The source branch preserves the console driver and record classes for a student database. The snapshot requires an additional `Database` class to build.

The original assignment files are on the [master branch](https://github.com/mrdc1790/COSC311---Program-2---Adam-Pollack/tree/master/src).

To inspect the original files locally:

    git fetch origin master
    git switch --detach FETCH_HEAD
